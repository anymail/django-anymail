# django-anymail security policy

## Supported versions

Security updates are provided for:

- The latest django-anymail release
- Any version identified as "extended support" (LTS) in the [release notes],
  through the date specified in those notes

Maintainers may also consider releasing security patches for other recent
major versions likely to be in widespread use, at their discretion. (For example,
when recent breaking changes could complicate adoption of the latest release.)

[release notes]: https://anymail.dev/en/stable/changelog/

## Reporting a vulnerability

To report a vulnerability in django-anymail, please **do not** use the public
issue tracker. Instead, either:

- [Report a vulnerability] through GitHub (preferred)
- Or email Anymail's maintainers at _security\<at>anymail\<dot>dev_

Projects must use supported versions of Python, Django, and other dependencies.
Vulnerability reports involving outdated dependencies are not considered valid.

Anymail is a small, volunteer-maintained open source project. We aim to respond
to security reports as quickly as possible, but please understand this could
take several days depending on maintainer availability.

[Report a vulnerability]: https://github.com/medmunds/django-anymail/security/advisories/new
